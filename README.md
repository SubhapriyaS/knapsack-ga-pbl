# Knapsack Optimization Using Genetic Algorithm

A Python implementation of a **Genetic Algorithm** for solving the **0/1 Knapsack Optimization Problem**.

## Features

- Binary chromosome representation
- Tournament selection
- Single-point crossover
- Bit-flip mutation
- Elitism
- Fitness tracking
- Population size and mutation rate experiments

## Results

**Knapsack Capacity:** 25  
**Best Total Weight:** 25  
**Best Total Value:** 63

The Genetic Algorithm successfully reached the optimal solution for the given dataset.
